# Accessibility — WCAG 2.2 AA (bắt buộc)

## 1. Semantic HTML trước, ARIA sau

Dùng thẻ gốc đúng nghĩa: `button`, `a`, `nav`, `main`, `header`, `footer`, `table`, `label`,
`fieldset`, `dialog`. ARIA **chỉ khi** không có thẻ gốc phù hợp.

| ❌ | ✅ |
|---|---|
| `<div onClick>` | `<button type="button">` |
| `<div class="link">` | `<a href="…">` |
| `<div role="button" tabindex="0">` | `<button>` |
| `<span>Label</span><input>` | `<label htmlFor="id">` + `<input id="id">` |
| `<div>` bọc list | `<ul><li>` |

Quy tắc ARIA số 1: **không dùng ARIA còn tốt hơn dùng sai ARIA**.

## 2. Bàn phím

Mọi thứ thao tác được bằng chuột phải thao tác được bằng bàn phím.

| Phím | Hành vi |
|------|---------|
| `Tab` / `Shift+Tab` | Di chuyển giữa các phần tử focus được |
| `Enter` | Kích hoạt button, link, submit form |
| `Space` | Kích hoạt button, toggle checkbox/switch |
| `Esc` | Đóng modal, dropdown, popover, huỷ inline edit |
| `↑ ↓` | Di chuyển trong menu, listbox, combobox, table row |
| `← →` | Di chuyển giữa tab, giữa cột trong data grid |
| `Home` / `End` | Đầu / cuối danh sách |
| `⌘K` / `Ctrl+K` | Mở global search — chuẩn chung của app hiện đại |

Luật:

- Thứ tự DOM = thứ tự đọc = thứ tự Tab. **Không dùng `tabindex > 0`**
- Modal/drawer: **focus trap** — Tab không thoát ra ngoài; đóng thì **trả focus về trigger**
- Dropdown mở: focus vào item đầu tiên; `Esc` đóng và trả focus về nút
- Không "focus bẫy" ngoài ý muốn (iframe, editor) — luôn có đường thoát bằng `Esc`
- **Skip link** "Bỏ qua điều hướng" là phần tử focus đầu tiên của trang

```tsx
<a href="#main"
   className="sr-only focus:not-sr-only focus:fixed focus:left-4 focus:top-4 focus:z-90
              focus:rounded-md focus:bg-background focus:px-4 focus:py-2 focus:ring-2 focus:ring-ring">
  Bỏ qua điều hướng
</a>
```

## 3. Focus indicator

- Luôn thấy rõ: `ring-2 ring-ring ring-offset-2`, contrast ≥ **3:1** so với nền kề
- Dùng `focus-visible` (không hiện ring khi click chuột) — nhưng **không bao giờ** xoá hẳn outline
- Focus không được bị `overflow: hidden` cắt mất → thêm `ring-offset` hoặc `overflow-visible`
- Phần tử focus phải cuộn vào tầm nhìn, không bị sticky header che (`scroll-margin-top`)

```css
/* ❌ Cấm tuyệt đối */
*:focus { outline: none; }

/* ✅ Đúng */
:focus-visible { outline: 2px solid hsl(var(--ring)); outline-offset: 2px; }
```

## 4. Contrast & màu sắc

| Đối tượng | Tối thiểu |
|-----------|-----------|
| Text thường | **4.5:1** |
| Text lớn (≥ 18.66px regular / ≥ 24px bold) | 3:1 |
| Icon, border input, ranh giới component | **3:1** |
| Focus indicator vs nền kề | 3:1 |

**Không truyền tải thông tin chỉ bằng màu.** Mỗi tín hiệu cần ít nhất 2 kênh:

| Tín hiệu | Kênh 1 | Kênh 2 | Kênh 3 |
|----------|--------|--------|--------|
| Lỗi field | màu đỏ | icon `AlertCircle` | text mô tả |
| Trạng thái | màu badge | chữ trong badge | icon (tuỳ chọn) |
| Tăng/giảm | màu | mũi tên ↑↓ | dấu +/− |
| Link trong đoạn văn | màu | underline | – |
| Bắt buộc | dấu `*` đỏ | `aria-required` | helper text |

Kiểm tra bằng chế độ giả lập mù màu (deuteranopia, protanopia) trong Chrome DevTools.

## 5. Ảnh, icon, nhãn

- Icon-only button **bắt buộc** có `aria-label`: `<Button size="icon" aria-label="Xoá đơn hàng">`
- Ảnh trang trí: `alt=""` + `aria-hidden="true"`
- Ảnh mang thông tin: `alt` mô tả **nội dung**, không phải "hình ảnh…"
- Icon trong button có text: `aria-hidden="true"` (tránh screen reader đọc 2 lần)
- Chart: có `aria-label` tóm tắt + bảng dữ liệu thay thế (hoặc `<figcaption>`)
- Avatar: `alt` là tên người, hoặc `aria-hidden` nếu tên đã hiện cạnh bên

## 6. Form & thông báo động

```tsx
<Label htmlFor="email">Email <span aria-hidden="true" className="text-destructive">*</span></Label>
<Input
  id="email" type="email" autoComplete="email" required
  aria-required="true"
  aria-invalid={!!error}
  aria-describedby={error ? "email-error" : "email-help"}
/>
{error
  ? <p id="email-error" role="alert" className="flex items-center gap-1.5 text-xs text-destructive">
      <AlertCircle className="size-3.5" aria-hidden="true" />{error}
    </p>
  : <p id="email-help" className="text-xs text-muted-foreground">Dùng email công ty.</p>}
```

Vùng cập nhật động:

- `aria-live="polite"` — kết quả tìm kiếm, số dòng đã chọn, toast success/info
- `aria-live="assertive"` / `role="alert"` — lỗi, cảnh báo cần chú ý ngay
- `aria-busy="true"` khi đang tải
- Sau khi submit lỗi: focus vào tóm tắt lỗi hoặc field lỗi đầu tiên

## 7. Target size & motion

- Touch target **≥ 44×44px** (Apple HIG). WCAG 2.2 AA (2.5.8) tối thiểu 24×24 — lấy 44 làm chuẩn
- Khoảng cách giữa 2 target ≥ 8px
- Vùng chạm có thể lớn hơn phần nhìn thấy (dùng pseudo-element mở rộng)
- `prefers-reduced-motion: reduce` phải được tôn trọng — tắt animation, giữ nguyên chức năng
- Không có nội dung tự động chạy/nháy > 3 lần/giây (nguy cơ động kinh)
- Carousel/slider tự chạy phải có nút tạm dừng

---

## 8. Zoom, reflow, ngôn ngữ

- Zoom **200%** không vỡ layout, không mất nội dung, không phải cuộn ngang
- Reflow ở 320px chiều rộng (WCAG 1.4.10) — nội dung xếp 1 cột
- Tăng `letter-spacing 0.12em`, `word-spacing 0.16em`, `line-height 1.5` vẫn đọc được (WCAG 1.4.12)
- `<html lang="vi">` — bắt buộc, ảnh hưởng cách screen reader phát âm
- Không dùng `user-scalable=no` hay `maximum-scale=1` trong meta viewport

---

## 9. Bảng dữ liệu

- Dùng `<table>` thật với `<thead>`, `<th scope="col">`, `<tbody>`
- Bảng có tiêu đề: `<caption>` hoặc `aria-labelledby`
- Checkbox chọn dòng: `aria-label="Chọn đơn hàng ORD-1234"` (không phải "Chọn")
- Checkbox chọn tất cả: `aria-label="Chọn tất cả"` + trạng thái `indeterminate`
- Sort: `aria-sort="ascending" | "descending" | "none"` trên `<th>`
- Không dùng `<table>` để dàn layout

| Bước | Công cụ | Mục tiêu |
|------|---------|----------|
| 1 | axe DevTools / `@axe-core/react` | 0 violation mức critical & serious |
| 2 | Lighthouse Accessibility | ≥ 95 điểm |
| 3 | Điều hướng **chỉ bằng bàn phím** | Hoàn thành được luồng chính, focus luôn thấy |
| 4 | Zoom 200% | Không vỡ layout |
| 5 | Giả lập mù màu (DevTools Rendering) | Mọi tín hiệu vẫn phân biệt được |
